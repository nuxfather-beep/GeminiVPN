# 🚀 GeminiVPN — Smart Unlocker

Легкий инструмент для прямого доступа к **Gemini**, **ChatGPT** и **Claude** из РФ. Работает без потери скорости и не требует постоянной работы в фоне.

## 📥 Как пользоваться
1. Скачайте архив в разделе [Releases](https://github.com/nuxfather-beep/GeminiVPN/releases).
2. Распакуйте и запустите `GeminiVPN.exe` **от имени Администратора**.
3. Нажмите кнопку **"ПОДКЛЮЧИТЬСЯ"**.

## ✨ Особенности
* **Скорость:** Нулевая задержка, так как трафик идет напрямую.
* **Умные списки:** Использует базы `dns.malw.link`.
* **Безопасность:** Открытый исходный код. Никаких скрытых прокси.

## ⚙️ Требования
* Windows 10 / 11 (x64)
* Права администратора
